# Package index

## All functions

- [`CI()`](CI.md) : Calculate the Convergence Index (CI) from a slope
  raster

- [`aspect()`](aspect.md) : Calculate topographic aspect from a DEM

- [`carmel`](carmel.md) : Digital Elevation Model of Mount Carmel

- [`dem`](dem.md) : Small Digital Elevation Model

- [`detrend()`](detrend.md) : Detrend a Digital Elevation Model

- [`dist_to_nearest()`](dist_to_nearest.md) : Calculate raster of
  distances to nearest feature

- [`extract2()`](extract2.md) : Extract raster values by lines or
  polygons

- [`flowlength()`](flowlength.md) : Calculate flow length

- [`focal2()`](focal2.md) : Apply a focal filter on a raster

- [`focal2r()`](focal2r.md) : Apply a focal filter on a raster (R)

- [`footprints()`](footprints.md) : Footprints

- [`golan`](golan.md) : Digital Elevation Model of Golan Heights

- [`landsat`](landsat.md) : RGB image of Mount Carmel

- [`layer_to_matrix()`](layer_to_matrix.md) :

  Get `stars` layer values as matrix

- [`layer_to_vector()`](layer_to_vector.md) :

  Get `stars` layer values as vector

- [`make_grid()`](make_grid.md) : Make 'stars' grid from 'sf' layer

- [`matrix_extend()`](matrix_extend.md) : Extend matrix

- [`matrix_get_neighbors()`](matrix_get_neighbors.md) : Get neighboring
  cell values for given matrix cell

- [`matrix_to_stars()`](matrix_to_stars.md) :

  Convert `matrix` to `stars`

- [`matrix_trim()`](matrix_trim.md) : Trim matrix

- [`mode_value()`](mode_value.md) : Mode

- [`normalize_2d()`](normalize_2d.md) : Normalize a 2D 'stars' object

- [`normalize_3d()`](normalize_3d.md) : Normalize a 3D 'stars' object

- [`rgb_to_greyscale()`](rgb_to_greyscale.md) : Convert RGB to greyscale

- [`slope()`](slope.md) : Calculate topographic slope from a DEM

- [`trim2()`](trim2.md) : Remove empty outer rows and columns

- [`w_azimuth()`](w_azimuth.md) : Create matrix with azimuths to center

- [`w_circle()`](w_circle.md) : Create matrix with circular weight
  pattern
